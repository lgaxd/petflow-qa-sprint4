CT-S4-03 — Controle de acesso por autenticação e perfil

Teste planejado e objetivo

verificar que rotas protegidas exigem login e que o perfil TUTOR não acessa funções de ADMIN.

Pré-condições

tutor A existe.

Dados de entrada

(a) sem login: URL /tutor/pets; (b) logado como tutor A: URL /admin/coupons; (c) API: GET /tutors com token do tutor A.

Procedimento / passos de teste

  1. Sem estar logado, digitar na barra a URL /tutor/pets.
  2. Fazer login como tutor A.
  3. Digitar na barra a URL /admin/coupons.
  4. No Swagger, autorizar com o token do tutor A e executar GET /tutors.

Dados de saída esperados

  • Passo 1: redirecionamento para /login.
  • Passo 3: redirecionamento para /tutor (a tela de cupons do admin não abre).
  • Passo 4: 403 com mensagem Você não tem permissão para acessar este recurso.

Rastreabilidade

  • PBI(s) validado(s): PBI-73
  • Teste automatizado: coleção Postman (automação API)
  • Massa de dados controlada e especificação completa: docs/casos-de-teste-manuais.md
