CT-S4-06 — Cadastro de tutor com senha fora da regra

Teste planejado e objetivo

verificar a regra de senha (mínimo 8 caracteres, com pelo menos uma letra e um número).

Pré-condições

nenhuma.

Dados de entrada

nome Tutor QA Senha Fraca · e-mail qa.fraca@petflow.test · senha e confirmação abcdefgh (8 letras, sem número).

Procedimento / passos de teste

  1. Acessar /register.
  2. Preencher os dados acima.
  3. Enviar o formulário.

Dados de saída esperados

  • Mensagem A senha deve ter no mínimo 8 caracteres, contendo pelo menos uma letra e um número.
  • Conta não criada.
  • (API) POST /tutors com a mesma senha → 400 com erro de validação no campo password.
  • Observação: senhas com menos de 8 caracteres são barradas antes pelo próprio navegador (atributo minLength), por isso o dado de entrada usa 8 letras sem número.

Rastreabilidade

  • PBI(s) validado(s): PBI-72
  • Teste automatizado: coleção Postman (automação API)
  • Massa de dados controlada e especificação completa: docs/casos-de-teste-manuais.md
