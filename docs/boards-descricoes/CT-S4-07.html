CT-S4-07 — Administrador cadastra cupom de teste

Teste planejado e objetivo

verificar que o administrador cadastra um cupom que passa a ficar disponível no catálogo.

Pré-condições

acesso à conta ADMIN.

Dados de entrada

código QA-S4-001 · status DISPONIVEL · validade 31/12/2099 · template 15% OFF em ração (20 pontos).

Procedimento / passos de teste

  1. Fazer login como administrador.
  2. Abrir Cupons (/admin/coupons) e clicar em Novo cupom.
  3. Preencher os dados e salvar.

Dados de saída esperados

  • Mensagem Cupom criado com sucesso.
  • Cupom QA-S4-001 listado com status DISPONIVEL.
  • (API) POST /coupons → 201.

Rastreabilidade

  • PBI(s) validado(s): PBI-86, PBI-87
  • Teste automatizado: coleção Postman (automação API)
  • Massa de dados controlada e especificação completa: docs/casos-de-teste-manuais.md
