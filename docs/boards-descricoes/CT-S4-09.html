CT-S4-09 — Cadastro de pet com data de nascimento futura

Teste planejado e objetivo

garantir que a data de nascimento precisa ser passada.

Pré-condições

logado como tutor A.

Dados de entrada

Pet Futuro QA · Cachorro · SRD · nascimento = hoje + 30 dias · 5 kg.

Procedimento / passos de teste

  1. Em Meus pets, clicar em Novo pet.
  2. Preencher os dados com a data futura e salvar.

Dados de saída esperados

  • Mensagem A data de nascimento deve ser uma data passada; o pet não aparece na lista.
  • Saldo continua 5.
  • (API) POST /pets → 400 com erro no campo birthDate (A data de nascimento deve ser uma data passada).

Rastreabilidade

  • PBI(s) validado(s): PBI-75
  • Teste automatizado: AUTO-GUI-06 (Selenium IDE) e coleção Postman
  • Massa de dados controlada e especificação completa: docs/casos-de-teste-manuais.md
