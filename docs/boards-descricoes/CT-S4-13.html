CT-S4-13 — Transição de status inválida do evento

Teste planejado e objetivo

garantir que um evento REALIZADO não volta para AGENDADO.

Pré-condições

evento do CT-S4-11 com status REALIZADO.

Dados de entrada

mesmo evento com status AGENDADO.

Procedimento / passos de teste

  1. Editar o evento e trocar o status para AGENDADO (ou PUT /health-events/{id} com status = AGENDADO).
  2. Salvar.

Dados de saída esperados

  • Mensagem de erro de transição inválida; o evento permanece REALIZADO.
  • (API) 422 Transição de status inválida.
  • Saldo continua 15.

Rastreabilidade

  • PBI(s) validado(s): PBI-79
  • Teste automatizado: coleção Postman (automação API)
  • Massa de dados controlada e especificação completa: docs/casos-de-teste-manuais.md
