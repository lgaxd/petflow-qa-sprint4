CT-S4-15 — Evento de saúde para pet inexistente

Teste planejado e objetivo

garantir que não é possível registrar evento para um pet que não existe.

Pré-condições

logado como tutor A (token no Swagger).

Dados de entrada

POST /health-events com petId = 999999999, eventTypeId = 3 (Consulta de Retorno), data = hoje + 30, status AGENDADO.

Procedimento / passos de teste

  1. No Swagger, autorizar com o token do tutor A.
  2. Executar POST /health-events com o corpo acima.

Dados de saída esperados

  • 404 Entidade não encontrada (Pet 999999999).
  • Nenhum evento criado.

Rastreabilidade

  • PBI(s) validado(s): PBI-79
  • Teste automatizado: coleção Postman (automação API)
  • Massa de dados controlada e especificação completa: docs/casos-de-teste-manuais.md
