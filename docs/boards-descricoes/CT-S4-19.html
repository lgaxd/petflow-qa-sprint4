CT-S4-19 — Resgate de cupom com saldo insuficiente

Teste planejado e objetivo

garantir que não é possível resgatar com saldo menor que o custo.

Pré-condições

saldo do tutor A = 45 (antes do passo 1 do CT-S4-18); cupom QA-S4-001 disponível.

Dados de entrada

POST /gamification/redeem com couponId do QA-S4-001.

Procedimento / passos de teste

  1. Na tela Resgatar cupons, verificar o botão do cupom.
  2. No Swagger, com o token do tutor A, executar o resgate.

Dados de saída esperados

  • Passo 1: botão desabilitado com o texto Pontos insuficientes.
  • Passo 2: 422 Pontos insuficientes, com detalhe de saldo atual 45 e necessário 50.
  • Saldo continua 45.

Rastreabilidade

  • PBI(s) validado(s): PBI-88
  • Teste automatizado: coleção Postman (automação API)
  • Massa de dados controlada e especificação completa: docs/casos-de-teste-manuais.md
