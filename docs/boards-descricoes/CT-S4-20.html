CT-S4-20 — Resgate de cupom já resgatado

Teste planejado e objetivo

garantir que um cupom não é resgatado duas vezes.

Pré-condições

CT-S4-18 executado.

Dados de entrada

POST /gamification/redeem com o mesmo couponId.

Procedimento / passos de teste

  1. Com o token do tutor A, executar novamente o resgate do QA-S4-001.

Dados de saída esperados

  • 422 (Cupom não está disponível para resgate).
  • Nenhum novo resgate criado; saldo inalterado.

Rastreabilidade

  • PBI(s) validado(s): PBI-88
  • Teste automatizado: coleção Postman (automação API)
  • Massa de dados controlada e especificação completa: docs/casos-de-teste-manuais.md
