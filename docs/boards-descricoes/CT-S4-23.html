CT-S4-23 — Cupons resgatados visíveis apenas ao dono

Teste planejado e objetivo

garantir que um tutor não vê os resgates de outro.

Pré-condições

CT-S4-18 executado (anotar o id do resgate). Tutor B cadastrado.

Dados de entrada

login do tutor B; GET /redeems/{id do resgate do tutor A} com token do tutor B.

Procedimento / passos de teste

  1. Logado como tutor B, abrir a lista de cupons resgatados.
  2. No Swagger, com o token do tutor B, executar GET /redeems/{id}.

Dados de saída esperados

  • Passo 1: lista vazia.
  • Passo 2: 403 Acesso negado.

Rastreabilidade

  • PBI(s) validado(s): PBI-89
  • Teste automatizado: coleção Postman (automação API)
  • Massa de dados controlada e especificação completa: docs/casos-de-teste-manuais.md
