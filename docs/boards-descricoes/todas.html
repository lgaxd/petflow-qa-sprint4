Task 155 · CT-S4-01

CT-S4-01 — Login válido do tutor

Teste planejado e objetivo

verificar que um tutor cadastrado entra no sistema com e-mail e senha válidos e é direcionado à área do tutor.

Pré-condições

CT-S4-04 executado (tutor A existe). Navegador sem sessão ativa.

Dados de entrada

e-mail qa.tutor.a@petflow.test · senha QaPetflow2026.

Procedimento / passos de teste

  1. Acessar /login no front.
  2. Informar o e-mail no campo E-mail.
  3. Informar a senha no campo Senha.
  4. Clicar em Entrar.

Dados de saída esperados

  • Mensagem Bem-vindo(a), Tutor!.
  • Redirecionamento para /tutor, com o título Olá, Tutor 👋.
  • (API) POST /auth/login → 200, corpo com token JWT e role = TUTOR.

Rastreabilidade

  • PBI(s) validado(s): PBI-73
  • Teste automatizado: AUTO-GUI-04 (Selenium IDE) e coleção Postman
  • Massa de dados controlada e especificação completa: docs/casos-de-teste-manuais.md

CT-S4-03 — Controle de acesso por autenticação e perfil

Teste planejado e objetivo

Pré-condições

tutor A existe.

Dados de entrada

Procedimento / passos de teste

  1. Sem estar logado, digitar na barra a URL /tutor/pets.
